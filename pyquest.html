PY-Quest

Android-Based Game for Learning Python Programming Fundamentals

PY-Quest is an Android-based educational game that helps students learn Python through interactive quizzes, coding challenges, and engaging gameplay. It combines learning and entertainment to make programming fundamentals easier, more enjoyable, and accessible for students.

Project Overview

A gamified mobile learning experience designed to improve Python programming skills through interactive assessments, progressive lessons, and engaging visual feedback.

What is PY-Quest?

Developed as a BSIT capstone project, PY-Quest transforms traditional programming lessons into an interactive Android game. Students can study lessons, answer coding-related questions, receive instant feedback, and unlock new topics as they progress through the learning journey.

The project focuses on making Python fundamentals easier to understand by combining quizzes, code completion, debugging activities, score tracking, and motivational progression mechanics.
